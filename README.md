# ValutaTrade Hub

Учебная консольная платформа для управления виртуальным валютным портфелем.
Пользователь регистрируется, пополняет баланс, покупает и продает валюту,
смотрит кошельки и общую стоимость портфеля. Котировки поступают из
CoinGecko и ExchangeRate-API; деньги и сделки в приложении виртуальные.

Поддерживаются **USD, EUR, GBP, RUB, BTC, ETH и SOL**.

## Как работает программа

CLI разбирает команды и вызывает Core Service. В ядре находятся модели
`User`, `Wallet`, `Portfolio`, реестр фиатных и криптовалют, проверка данных
и операции с портфелем. Слой `infra` предоставляет общие настройки
`SettingsLoader` и доступ к JSON через `DatabaseManager`.

При регистрации создается пустой портфель. `deposit` пополняет USD-баланс;
покупка списывает `amount × rate` USD и добавляет валюту, продажа делает
обратное. `amount` — количество единиц валюты, а не сумма долларов.
Кошелек покупаемой валюты создается автоматически. Сделки и просмотр портфеля
доступны после `login`; данные сохраняются между запусками, сессия — до выхода.

Parser Service загружает курсы, сохраняет историю и обновляет локальный кэш.
Core Service читает этот кэш для сделок и конвертации стоимости портфеля.
Пароли хранятся в виде хешей, а операции и ошибки — в журналах с ротацией.

## Установка и запуск

Нужны **Python 3.12+** и **uv**. Установите проект:

```bash
git clone https://github.com/Xlemon5/finalproject_Zadorozhnii_M26-555.git
cd finalproject_Zadorozhnii_M26-555
uv sync --locked
```

В корне проекта создайте `.env` по шаблону [.env.example](.env.example).
Если файл уже настроен, используйте его. Ключ ExchangeRate-API берется
из личного кабинета сервиса:

```dotenv
EXCHANGERATE_API_KEY=ваш_ключ
COINGECKO_API_KEY=
```

Без `COINGECKO_API_KEY` клиент пробует публичный доступ; при HTTP 401/403
укажите Demo-ключ CoinGecko. `.env` читается автоматически из текущей папки
и исключен из Git. Переменные окружения имеют приоритет над файлом.

Запустите кошелек из папки проекта:

```bash
uv run wallet
```

Также доступны `uv run project` и `uv run python main.py`.
После перезапуска приложения нужно снова выполнить `login`.

## Примеры команд CLI

Команды ниже вводятся внутри запущенного кошелька. Регистрация создает
пользователя, вход открывает сессию, затем можно пополнить баланс и торговать:

```text
register --username alice --password 1234
login --username alice --password 1234
deposit --amount 10000
update-rates
show-rates --top 2
buy --currency BTC --amount 0.005
sell --currency BTC --amount 0.002
show-portfolio
show-portfolio --base EUR
get-rate --from USD --to BTC
```

`show-portfolio` выводит балансы и общую стоимость в USD или выбранной базе.
`get-rate` показывает прямой и обратный курс с датой обновления.
Стоимость покупки зависит от текущих котировок и доступного USD-баланса.

Примеры ошибок после этого сценария:

```text
> sell --currency BTC --amount 10
Недостаточно средств: доступно 0.0030 BTC, требуется 10.0000 BTC

> get-rate --from ABC --to USD
Неизвестная валюта 'ABC'
Поддерживаемые коды: BTC, ETH, EUR, GBP, RUB, SOL, USD
```

Ошибка выводится понятным сообщением, после нее можно ввести следующую команду.
`help` показывает справку, `currencies` — список валют, `logout` завершает
сессию пользователя, `exit` — приложение.

## Запуск Parser Service

Парсер запрашивает криптовалюты у CoinGecko, фиатные валюты — у ExchangeRate-API.
Из кошелька можно обновить все курсы или выбрать источник, затем посмотреть кэш:

```text
update-rates
update-rates --source coingecko
update-rates --source exchangerate
show-rates
show-rates --currency RUB
show-rates --top 2 --base EUR
```

`--top` выбирает самые дорогие криптовалюты по цене одной единицы.
Для отдельного запуска парсера используйте обычный терминал из папки проекта:

```bash
uv run rates-parser
uv run rates-parser --watch --interval 300
```

Первая команда выполняет один цикл обновления. Вторая обновляет курсы сразу,
затем ждет 300 секунд после каждого цикла; остановка — Ctrl+C.
Если один API недоступен, успешные данные другого сохраняются, ошибка попадает
в `logs/parser.log`.

## Кэш и TTL

`data/rates.json` хранит последние курсы, источник и время получения каждой
пары (`updated_at`), а также время обновления снимка (`last_refresh`).
`data/exchange_rates.json` хранит историю измерений. Запись выполняется
атомарной заменой каждого файла.

**TTL — срок актуальности кэша, по умолчанию 300 секунд (5 минут)**.
Он задается параметром `rates_ttl_seconds` в секции `[tool.valutatrade]`
файла `pyproject.toml` и считается от времени получения котировки.
Если курс отсутствует или устарел, сделки, оценка портфеля и `get-rate`
предлагают выполнить `update-rates`. `show-rates` позволяет посмотреть старые
значения с отметкой об устаревании. Кошелек сам не запрашивает API;
обновление выполняется явно или через запущенный планировщик парсера.
