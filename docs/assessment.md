## Воспроизведение проверки

```bash
uv sync --locked
make lint
make test
make build
uv run python scripts/record_demo.py
```

Для записи демо нужен ключ ExchangeRate-API в `.env` или окружении
Само демо записано 8 октября 2026 года в окне Terminal с обоими внешними API
API-ответы не подменяются в записи; в модульных тестах они заменяются тестовыми данными

`data/users.json` и `data/portfolios.json` создаются при запуске кошелька,
`data/rates.json` и `data/exchange_rates.json` — при первом успешном обновлении
Личные данные и ключи не включаются в репозиторий или сборку

## Принятые решения

- `deposit` пополняет виртуальный USD-баланс; покупка списывает USD, продажа начисляет USD
- Core Service читает кэш; устаревшие котировки требуют команды `update-rates`
- Время получения ответа определяет TTL; время обновления самим API сохраняется отдельно
- В ExchangeRate-API значения USD→валюта инвертируются перед сохранением пары валюта→USD
- Файлы истории и кэша заменяются атомарно по отдельности; общей транзакции двух файлов нет
- Работа нескольких процессов поддерживается для парсера; операции с портфелями рассчитаны на один процесс кошелька
